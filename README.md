# Yuri Bizzoni — personal site

Static site served by GitHub Pages at https://yuri-bizzoni.github.io/yuribizzoni/

- `index.html`, `publications.html`, `projects.html`, `teaching.html`, `contact.html`: the pages (plain HTML)
- `style.css`: the single stylesheet (light and dark mode, no frameworks)
- `ml-humanities/`: course materials for *Machine Learning for the Humanities* (notebooks, slides, classroom game)
- `happiness/`: Happiness, a small agent you can run yourself, with a lexicon of happiness built in (see [its README](happiness/README.md))

To add a publication, copy one `<li>…</li>` block in `publications.html` and edit it.
